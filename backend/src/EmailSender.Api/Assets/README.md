# Imagem da assinatura

Coloque a imagem da assinatura nesta pasta e informe o caminho relativo em
`Assinatura:CaminhoImagem`, por exemplo:

```json
"CaminhoImagem": "Assets/assinatura.png"
```

A imagem será incorporada ao e-mail como recurso inline e inserida na posição
do marcador `{{Imagem}}` definido em `Assinatura:Html`.
